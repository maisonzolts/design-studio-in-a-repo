# team-comms

## Purpose
Reusable, sanitized operating procedure for team comms. This public version contains no client or owner records.

## Workflow
1. Resolve the recipient through an allowlisted role roster.
2. Write as Svetlana, never impersonating the owner.
3. Send only pre-authorized routine briefs; draft everything else.
4. Never use this path for clients or vendors.

## Calls and chain
Calls or hands off to: `brief-machine`.

## Dependencies
`Slack or Gmail, private team roster`

## Adapter note
Replace channel adapters and roster source.

## Safety
- Read before writing.
- Keep credentials in environment variables.
- Keep client, health, financial, and state data outside this repository.
- External messages, publishing, scheduling, CRM writes, and financial actions require explicit human approval.
