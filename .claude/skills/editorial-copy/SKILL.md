# editorial-copy

## Purpose
Reusable, sanitized operating procedure for editorial copy. This public version contains no client or owner records.

## Workflow
1. Review clarity, voice, specificity, proof, objections, risk, and action.
2. Revise one sweep at a time.
3. Preserve approved facts.
4. Finish with copyeditor.

## Calls and chain
Calls or hands off to: `copyeditor`.

## Dependencies
`none`

## Adapter note
No integration required.

## Safety
- Read before writing.
- Keep credentials in environment variables.
- Keep client, health, financial, and state data outside this repository.
- External messages, publishing, scheduling, CRM writes, and financial actions require explicit human approval.
