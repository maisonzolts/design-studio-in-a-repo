# printlayoutdesign

## Purpose
Reusable, sanitized operating procedure for printlayoutdesign. This public version contains no client or owner records.

## Workflow
1. Load brief, copy, brand tokens, references, and print specs.
2. Solve hierarchy and pagination in a measured comp.
3. Transfer approved geometry into InDesign in small paced calls.
4. Apply styles and assets.
5. Run structural and export preflight before review.

## Calls and chain
Calls or hands off to: `design-best-practices, edit-design, paintbrush, asset-population, launch-indesign-mcp`.

## Dependencies
`InDesign, Windows COM or UXP bridge, Playwright for measured HTML comps`

## Adapter note
Replace InDesign transfer with another professional layout engine.

## Safety
- Read before writing.
- Keep credentials in environment variables.
- Keep client, health, financial, and state data outside this repository.
- External messages, publishing, scheduling, CRM writes, and financial actions require explicit human approval.
