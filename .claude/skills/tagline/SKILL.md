# tagline

## Purpose
Reusable, sanitized operating procedure for tagline. This public version contains no client or owner records.

## Workflow
1. Load positioning, audience, promise, voice, and naming constraints.
2. Explore distinct strategic territories.
3. Remove generic, unprovable, and category-cliché options.
4. Present a short rationale and run copyeditor.

## Calls and chain
Calls or hands off to: `brandscript, copyeditor`.

## Dependencies
`brand profile`

## Adapter note
No integration required.

## Safety
- Read before writing.
- Keep credentials in environment variables.
- Keep client, health, financial, and state data outside this repository.
- External messages, publishing, scheduling, CRM writes, and financial actions require explicit human approval.
