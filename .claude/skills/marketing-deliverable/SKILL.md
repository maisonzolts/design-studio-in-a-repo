# marketing-deliverable

## Purpose
Reusable, sanitized operating procedure for marketing deliverable. This public version contains no client or owner records.

## Workflow
1. Load brief, brand profile, copy, assets, and constraints.
2. Choose the medium-specific production skill.
3. Create internal drafts through edit-design.
4. Preflight copy, visual quality, and output specs.
5. Deliver for owner review, never publish automatically.

## Calls and chain
Calls or hands off to: `project-pipeline, design-best-practices, edit-design, copyeditor`.

## Dependencies
`depends on selected medium`

## Adapter note
Replace production adapters while preserving review gates.

## Safety
- Read before writing.
- Keep credentials in environment variables.
- Keep client, health, financial, and state data outside this repository.
- External messages, publishing, scheduling, CRM writes, and financial actions require explicit human approval.
