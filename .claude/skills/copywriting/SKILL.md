# copywriting

## Purpose
Reusable, sanitized operating procedure for copywriting. This public version contains no client or owner records.

## Workflow
1. Confirm audience, offer, page goal, and proof.
2. Build the message hierarchy.
3. Draft headlines, body, proof, objections, and calls to action.
4. Run editorial-copy then copyeditor.

## Calls and chain
Calls or hands off to: `brandscript, editorial-copy, copyeditor`.

## Dependencies
`brand profile and approved offer facts`

## Adapter note
Use your own brand repository and CMS.

## Safety
- Read before writing.
- Keep credentials in environment variables.
- Keep client, health, financial, and state data outside this repository.
- External messages, publishing, scheduling, CRM writes, and financial actions require explicit human approval.
