# brandscript

## Purpose
Reusable, sanitized operating procedure for brandscript. This public version contains no client or owner records.

## Workflow
1. Load the brand profile and interview inputs.
2. Draft who, what, why, how, audience, promise, and proof.
3. Keep claims evidence-based and voice-consistent.
4. Run copyeditor before review.

## Calls and chain
Calls or hands off to: `identify-brand-identity, copyeditor`.

## Dependencies
`brand profile`

## Adapter note
Use any structured brand repository that can supply approved facts.

## Safety
- Read before writing.
- Keep credentials in environment variables.
- Keep client, health, financial, and state data outside this repository.
- External messages, publishing, scheduling, CRM writes, and financial actions require explicit human approval.
