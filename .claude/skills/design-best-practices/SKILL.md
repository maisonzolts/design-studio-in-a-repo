# design-best-practices

## Purpose
Reusable, sanitized operating procedure for design best practices. This public version contains no client or owner records.

## Workflow
1. Load medium-specific constraints and brand tokens.
2. Check hierarchy, composition, typography, spacing, contrast, and production constraints.
3. Record decisions that affect downstream build.
4. Return control to the production skill.

## Calls and chain
Calls or hands off to: `edit-design, icon-selection`.

## Dependencies
`brand tokens and reference library`

## Adapter note
Point references at your own approved design doctrine.

## Safety
- Read before writing.
- Keep credentials in environment variables.
- Keep client, health, financial, and state data outside this repository.
- External messages, publishing, scheduling, CRM writes, and financial actions require explicit human approval.
