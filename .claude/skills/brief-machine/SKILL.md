# brief-machine

## Purpose
Reusable, sanitized operating procedure for brief machine. This public version contains no client or owner records.

## Workflow
1. Resolve scope, owner, inputs, deliverables, deadline, and acceptance criteria.
2. Ask only for facts that cannot be looked up.
3. Draft the brief.
4. Route through team-comms; never send without the configured approval.

## Calls and chain
Calls or hands off to: `delegation-oscillation, team-comms, copyeditor`.

## Dependencies
`Gmail, task manager`

## Adapter note
Replace Gmail/task creation with your team communication stack.

## Safety
- Read before writing.
- Keep credentials in environment variables.
- Keep client, health, financial, and state data outside this repository.
- External messages, publishing, scheduling, CRM writes, and financial actions require explicit human approval.
