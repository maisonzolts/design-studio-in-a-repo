# delegation-oscillation

## Purpose
Reusable, sanitized operating procedure for delegation oscillation. This public version contains no client or owner records.

## Workflow
1. Identify the decision, required judgment, reversibility, and access.
2. Compare owner attention with delegation overhead.
3. Choose a responsible role, not a named person.
4. If delegated, hand off through brief-machine.

## Calls and chain
Calls or hands off to: `brief-machine`.

## Dependencies
`task manager, team capacity data`

## Adapter note
Replace the task manager and rate/capacity inputs.

## Safety
- Read before writing.
- Keep credentials in environment variables.
- Keep client, health, financial, and state data outside this repository.
- External messages, publishing, scheduling, CRM writes, and financial actions require explicit human approval.
