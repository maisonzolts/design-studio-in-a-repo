# web-conversion-doctrine

## Purpose
Reusable, sanitized operating procedure for web conversion doctrine. This public version contains no client or owner records.

## Workflow
1. Check page intent, audience stage, and conversion path.
2. Apply legitimate information architecture, proof, accessibility, SEO, analytics, and form principles.
3. Return constraints to the execution skill.

## Calls and chain
Calls or hands off to: `websitelayoutdesign, developwebsite`.

## Dependencies
`none`

## Adapter note
Replace reference doctrine with your approved web standards.

## Safety
- Read before writing.
- Keep credentials in environment variables.
- Keep client, health, financial, and state data outside this repository.
- External messages, publishing, scheduling, CRM writes, and financial actions require explicit human approval.
