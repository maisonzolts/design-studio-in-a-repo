# asset-population

## Purpose
Reusable, sanitized operating procedure for asset population. This public version contains no client or owner records.

## Workflow
1. Read the copy and identify each asset slot's job.
2. Resolve approved assets from the brand profile.
3. Place assets without distorting, inventing, or silently cropping meaning.
4. Review each section visually through edit-design.

## Calls and chain
Calls or hands off to: `identify-brand-identity, edit-design, paintbrush`.

## Dependencies
`InDesign or CMS, file/asset storage`

## Adapter note
Replace InDesign/CMS placement with the target design tool's asset API.

## Safety
- Read before writing.
- Keep credentials in environment variables.
- Keep client, health, financial, and state data outside this repository.
- External messages, publishing, scheduling, CRM writes, and financial actions require explicit human approval.
