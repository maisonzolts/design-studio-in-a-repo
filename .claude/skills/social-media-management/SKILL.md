# social-media-management

## Purpose
Reusable, sanitized operating procedure for social media management. This public version contains no client or owner records.

## Workflow
1. Confirm account goals, audience, consent, and channel rules.
2. Plan covers and grid before full production.
3. Create and review copy/visuals.
4. Require explicit approval before scheduling or publishing.
5. Report outcomes against business goals.

## Calls and chain
Calls or hands off to: `project-pipeline, edit-design, copyeditor`.

## Dependencies
`social scheduler, design tool, analytics`

## Adapter note
Replace platform-specific scheduling and reporting adapters.

## Safety
- Read before writing.
- Keep credentials in environment variables.
- Keep client, health, financial, and state data outside this repository.
- External messages, publishing, scheduling, CRM writes, and financial actions require explicit human approval.
