# edit-design

## Purpose
Reusable, sanitized operating procedure for edit design. This public version contains no client or owner records.

## Workflow
1. Name the section and intended visual change.
2. Inspect the current output.
3. Make one bounded change.
4. Capture and inspect the result.
5. Check neighboring sections and production constraints.
6. Repeat until the section passes.

## Calls and chain
Calls or hands off to: `design-best-practices, icon-selection`.

## Dependencies
`browser capture or InDesign`

## Adapter note
Use the target application's capture/export mechanism.

## Safety
- Read before writing.
- Keep credentials in environment variables.
- Keep client, health, financial, and state data outside this repository.
- External messages, publishing, scheduling, CRM writes, and financial actions require explicit human approval.
