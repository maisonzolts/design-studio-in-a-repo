# reference-capture

## Purpose
Reusable, sanitized operating procedure for reference capture. This public version contains no client or owner records.

## Workflow
1. Capture the complete reference, including lazy-loaded states.
2. Record viewport, interaction, typography, spacing, motion, and components.
3. Separate observed facts from interpretation.
4. Write a build-oriented reference spec.

## Calls and chain
Calls or hands off to: `websitelayoutdesign, brand-research-dossier`.

## Dependencies
`Playwright/browser capture; optional video tools`

## Adapter note
Use another deterministic capture stack.

## Safety
- Read before writing.
- Keep credentials in environment variables.
- Keep client, health, financial, and state data outside this repository.
- External messages, publishing, scheduling, CRM writes, and financial actions require explicit human approval.
