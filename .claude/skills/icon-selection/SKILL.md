# icon-selection

## Purpose
Reusable, sanitized operating procedure for icon selection. This public version contains no client or owner records.

## Workflow
1. Define the communication job.
2. Choose one coherent visual grammar.
3. Check optical weight, stroke, scale, and licensing.
4. Place and review through edit-design.

## Calls and chain
Calls or hands off to: `edit-design`.

## Dependencies
`approved brand asset library`

## Adapter note
Use your own licensed icon library.

## Safety
- Read before writing.
- Keep credentials in environment variables.
- Keep client, health, financial, and state data outside this repository.
- External messages, publishing, scheduling, CRM writes, and financial actions require explicit human approval.
